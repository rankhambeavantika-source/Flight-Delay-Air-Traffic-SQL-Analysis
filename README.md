# ✈️ Flight Delay & Air Traffic Analysis — SQL Project

## 📌 Project Overview

This project analyzes flight and air traffic data using MySQL to understand passenger traffic, flight operations, load factor, capacity utilization, and the impact of COVID-19 on the aviation industry.

The analysis focuses on identifying yearly and monthly trends and comparing domestic and international aviation activity.

---

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- GitHub

---

## 🎯 Business Objectives

The project answers key business questions such as:

- What is the overall passenger traffic?
- Which year had the highest and lowest passenger traffic?
- Which year had the highest and lowest flight traffic?
- How does domestic traffic compare with international traffic?
- Which year had the highest load factor?
- How did passenger and flight traffic change during COVID-19?
- How did capacity utilization change over time?
- When did the aviation industry show signs of recovery?



## 📊 Analysis Performed

### 1. Data Exploration
- Table structure inspection
- Record count

### 3. Flight Analysis
- Total flights

### 4. Load Factor Analysis

### 5. RPM & ASM Analysis
- Revenue Passenger Miles (RPM)
- Available Seat Miles (ASM)

- Capacity utilization

### 6. COVID-19 Impact Analysis
- Comparison of 2019, 2020 and 2021
- Passenger traffic impact
- Flight traffic impact
- Load factor changes
- RPM and ASM changes
- Recovery analysis
